# Zotero 重复 PDF 清理 — 把硬盘空间还给你

下载文件夹里躺着很多"其实你早就有了"的 PDF。同一篇论文，Zotero 存了一份，下载文件夹里还留着另一份——你认不出来，因为它改过名。

这个工具帮你**找出这些重复文件，安全地送进回收站**。

> 如果你更喜欢命令行，欢迎移步到 [zotero-cleaner-cli](https://github.com/Tenktau/zotero-cleaner-cli)，这是我针对同一需求同步开发的命令行版本。

## 它做什么

- **只删重复**：按文件内容识别，不认文件名。改名、加 `(1)`、`(2)`，都躲不过。
- **只动一处**：只清理你指定的文件夹，Zotero 库里的附件原封不动。
- **删得安心**：删除先进回收站，误删也能找回来。
- **开箱即用**：自动识别 Zotero 附件目录和下载文件夹，也可在界面里点「浏览…」手动调整。

## 一分钟上手

打开程序，依次三下：

1. 自动找到 Zotero 附件目录和你的「下载」文件夹（找不到就点「浏览…」自己选）。
2. 点「开始扫描」。
3. 勾选要清理的文件（默认全选），点「移入回收站」。

> 目前仅支持 Windows（删除依赖系统回收站 API）。绿色便携，无需安装，不写注册表。

## 下载即用

到 [Releases](https://github.com/Tenktau/zotero-cleaner-gui/releases) 页面下载最新版 **`ZoteroPdfCleaner-windows.zip`**，解压双击即可。

> **下载后浏览器弹出"警告"是正常的**：Windows 对"从网上下载的未签名程序"会提示「不安全 / 未知发布者」，这是系统对未知程序的例行检查，**不是文件有问题**。

### 自行编译（可选）

Windows 10/11 自带 .NET Framework，**无需安装任何 SDK**：

1. 下载或克隆源码。
2. 双击 `build.cmd`。
3. 仓库目录里就生成了 `ZoteroPdfCleaner.exe`。

## 实现原理

1. 给 Zotero 附件目录里的每个文件算一个"内容指纹"（SHA-256），建立索引。
2. 扫描目标文件夹：先用**文件大小**粗筛——大小都不一样，内容必然不同——再对嫌疑文件比对指纹。
3. 指纹一致 → 判定重复 → 勾选确认 → **移入回收站**（可恢复，不是永久删除）。

## 自定义（可选）

默认自动识别 Zotero 附件目录和系统下载文件夹。需要手动指定时，直接在界面顶部的两个输入框里点「浏览…」选择即可。
